Справка по SpEL — формулы и фильтр строк

Главное правило: название колонки всегда в квадратных скобках с кавычками — ['Название колонки']. Название должно точно совпадать с заголовком в отчёте (или в справочнике — для LOOKUP-полей). Пробелы, точки, любые символы внутри — не проблема, скобки работают всегда одинаково.

Формулы (тип колонки COMPUTED)
Разница двух цен['Цена'] - ['РРЦ']
Процент отклонения(['Цена'] - ['РРЦ']) / ['РРЦ'] * 100
Склеить текст из колонок['Город'] + ', ' + ['Улица']
Колонка с пробелом/точкой в названии['Цена со скидкой'] - ['Цена до скидки']
Если-то-иначе (тернарный оператор)['Цена'] > ['РРЦ'] ? 'Дороже' : 'Дешевле или равно'
Взять часть текста (первые 5 символов)['Артикул'].substring(0, 5)
Перевести текст в верхний регистр['Бренд'].toUpperCase()
Использовать значение LOOKUP-колонки в формуле Укажите заголовок LOOKUP-колонки (не исходный столбец справочника): ['Юр. лицо'] + ' (' + ['Город юр. лица'] + ')'
Условия (для «Фильтр строк», а также внутри формул через ?:)
Ячейка не пустая['ОГРН'] != null and ['ОГРН'] != ''
Ячейка пустая['ОГРН'] == null or ['ОГРН'] == ''

Число в диапазоне['Цена'] >= 100 and ['Цена'] <= 5000
Оба условия сразу (И)['ОГРН'] != null and ['Цена'] > 0
Любое из условий (ИЛИ)['Статус'] == 'Активен' or ['Статус'] == 'Новый'

Оставить только строки, где нашёлся LOOKUP ['Юр. лицо'] != null (LOOKUP-колонка не нашла совпадение → пусто)
Частые ошибки
  • Название колонки без квадратных скобок (Цена вместо ['Цена']) — выражение не соберётся, если в названии есть пробел или оно начинается с цифры.
  • Сравнение текста и числа: ['Цена'] == '100' (в кавычках) не то же самое, что ['Цена'] == 100.
  • Обращения вроде T(Math).round(...), new ... или вызовы статических Java-методов намеренно заблокированы из соображений безопасности (формулы пишут любые пользователи с доступом к конфигу) — доступны только арифметика и обычные методы самих значений (.contains(), .substring(), .toUpperCase() и т.п.). Округление не нужно — числа форматирует сам генератор файла.
  • Ошибка в формуле → эта ячейка станет пустой, весь отчёт не остановится. Ошибка в фильтре → строка просто не попадёт в результат. Подробности — в логах сервера.
